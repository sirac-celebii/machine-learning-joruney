# 🏋️‍♂️ Crowdedness at the Campus Gym Prediction
- Bu proje, kampüs spor salonundaki kişi sayısını (crowdedness) tahmin etmek için makine öğrenmesi modelleri kullanılarak geliştirilmiştir.

# 🧠 Kullanılan Modeller
- Linear Regression
- Ridge / Lasso Regression
- K-Nearest Neighbors(KNN)
- Decision Tree Regressor
- Random Forest Regressor
- Support Vector Regressor(SVR)

# 🛠️ Kullanılan Kütüphaneler
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

# 🔄 Yapılan İşlemler
- Veri temizleme ve ön işleme
- Tarih sütunundan yeni özellikler çıkarma
- Keşifsel Veri Analizi (EDA)
- Train-Test split
- StandardScaler ile ölçekleme
- Model eğitimi ve karşılaştırma
- RandomizedSearchCV ile hiperparametre optimizasyonu
- En iyi modellerin yeniden değerlendirilmesi

# 🏆 Sonuç
- Random Forest ve KNN modelleri, yapılan optimizasyonlardan sonra en iyi performansı göstermiştir.
