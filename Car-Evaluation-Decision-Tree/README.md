# 🚗 Car Evaluation Dataset - Decision Tree Classification

Bu proje, Car Evaluation veri seti kullanılarak araçların kabul edilebilirlik sınıfını tahmin etmek için **öğrenme ve pratik yapma amacıyla** hazırlanmıştır

---

## 🛠️ Kullanılan Kütüphaneler

- pandas  
- numpy  
- matplotlib  
- seaborn  
- scikit-learn  

---

## 🔄 Yapılan İşlemler

- Veri yükleme ve inceleme (EDA)
- Kategorik değişken analizi
- Veri ön işleme (Ordinal Encoding)
- Train/Test split
- Decision Tree modeli eğitimi
- Model değerlendirme (accuracy, classification report, confusion matrix)
- Hyperparameter tuning (GridSearchCV)

---

## 🌳 Kullanılan Model

- Decision Tree Classifier

---

## 🎯 Amaç

Bu proje:
- Makine öğrenmesi pipeline mantığını öğrenmek  
- Veri ön işleme adımlarını anlamak  
- Decision Tree algoritmasını uygulamak  
- Model tuning sürecini deneyimlemek  

amacıyla hazırlanmıştır.
