# 🩺 Pima Indians Diabetes Prediction

* Bu proje, **Pima Indians Diabetes** veri seti kullanılarak bireylerin diyabet hastası olup olmadığını tahmin etmek amacıyla geliştirilmiştir.

# 🧠 Kullanılan Modeller

* Logistic Regression
* Support Vector Classifier (SVC)
* Decision Tree Classifier
* K-Nearest Neighbors (KNN)
* Random Forest Classifier
* AdaBoost Classifier

# 🛠️ Kullanılan Kütüphaneler

* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

# 🔄 Yapılan İşlemler

* Veri setinin incelenmesi
* Keşifsel Veri Analizi (EDA)
* Korelasyon analizi ve görselleştirme
* Eksik verilerin (0 değerleri) tespit edilmesi
* Median Imputation ve KNN Imputer yöntemlerinin karşılaştırılması
* Hybrid (Median + KNN Imputation) yaklaşımının uygulanması
* StandardScaler ile ölçekleme
* Train-Test Split
* AdaBoost modeli ile eğitim
* GridSearchCV ile hiperparametre optimizasyonu
* Farklı makine öğrenmesi modellerinin performans karşılaştırması

# 🏆 Sonuç

* Farklı eksik veri tamamlama yöntemleri karşılaştırılmış ve **Hybrid (Median + KNN Imputation)** yaklaşımının en başarılı sonuçları verdiği gözlemlenmiştir.
* Ardından farklı sınıflandırma algoritmaları değerlendirilmiş ve en yüksek doğruluk oranına sahip modeller karşılaştırılmıştır.
